# Gaucho Churrascaria

Um trabalho universitário sobre um restaurante, para aprimorarmos nossas habilidades de HTML, visando a criação de um site para web. 

## 🚀 Funcionalidades

- **Página inicial** com botões para as demais páginas
- **Carta de vinhos**  organizado por categorias, preços e descrições
- **Cardápio digital** organizado por categorias, preços e descrições
- **Delivery** para fazer o pedido online
- **Depoimentos de clientes** com avaliações reais
- **Fale conosco** informações de contato
- **Nossa unidade** com mapa incorporado e horário de funcionamento
- **Quem somos** descrição sobre o restaurante
- **Sistema de reservas** via formulário
- **Trabalhe conosco** informações de contato

## 🛠️ Tecnologias
